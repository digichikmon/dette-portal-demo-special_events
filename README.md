# D'Ette Services — Special Events Portal Demo

A static client portal for D'Ette Services (Houston, TX) — **special events only**.
Plain HTML / CSS / JS. No build step, no framework, no bundler.

## Pages

| File | Step | Description |
|---|---|---|
| `index.html` | Login | Sign in / create account |
| `dashboard.html` | 01 | Event calendar dashboard (month grid + upcoming list) |
| `add-event.html` | 02 | Add to calendar form (special event activity types) |
| `contacts.html` | 03 | Event vendor directory and emergency contacts |
| `shop.html` | 04 | 2027 calendar pre-order and event merch shop |

## Design system

- Same brand tokens as the demo portal (`css/style.css`): ink, ivory, terracotta accent, sand tint.
- Special events theme: deep navy sidebar (`#141E2E`), warm gold nav highlights (`#A09060`).
- Fonts bundled in `assets/fonts/` — Gloock, Italiana, Instrument Sans, Geist Mono.

## Status

Demo build · Dom Design Studio · Not for production use.
